# ADR-0002: 안티그래비티 에이전트 중심 올인원 워크플로우 및 사용자 컨펌 게이트웨이 도입

- **상태:** 승인됨 (Accepted)
- **최종 개정일:** 2026-08-31
- **작성자:** mmmphyun
- **범위:** security-agent-toolkit 전반

---

## 1. 배경 및 문제 정의 (Context)

기존 파이프라인(ADR-0001)은 GitHub Actions Cron과 단순 파이썬 스크립트(`generate_draft.py`)를 통해 Gemini API를 1회 호출하여 초안을 생성하는 방식이었음.

### 기존 방식의 한계점
1. **맥락 수집 한계:** 외부 커리큘럼 자료나 비공개 SPA 웹페이지를 단순 스크립트로 인제스트하기 어려우며, 문제 해결 과정의 고민과 나이브한 베이스라인 간의 미묘한 기술적 의사결정 맥락을 파악하는 데 한계가 존재함.
2. **실시간 대화형 피드백 부재:** 단순 CI 기반 생성 방식은 초안의 설명 보강, Mermaid 다이어그램 수정, 문체 조정 등의 상호작용적 개선이 어려움.
3. **무단 커밋/PR 리스크:** 검증되지 않은 초안이 사용자 검토 없이 자동으로 PR로 발행되어 불필요한 노이즈를 유발할 수 있음.

## 2. 핵심 아키텍처 의사결정 (Decisions)

### D-1. 안티그래비티(Antigravity) 에이전트 중심 올인원 오케스트레이션 채택
- 단순 파이썬 API 호출 대신 안티그래비티 에이전트를 메인 오케스트레이터로 전환함.
- 에이전트가 직접 파일 시스템을 탐색하고, 코드 실행 및 리팩터링 대조(`*llm.py`), 5단 ADR 초안 작성을 종합적으로 수행함.

### D-2. 매주 평일 17시 정기 스케줄 확립
- 안티그래비티 내장 스케줄러(`schedule` 크론: `0 17 * * 1-5`)를 등록하여 수업 종료 시점에 자율적으로 기상하여 당일 학습 코드를 스캔 및 작업하도록 구성함.

### D-3. `humanize-korean` (`im-not-ai`) 스킬 내재화
- 번역투, 기계적 대구, AI 상투어를 배제하고 시니어 엔지니어링 테크니컬 라이팅 어조를 블로그 초안에 적용함.

### D-4. 결정론적 하네스 자가 교정 (Self-correction Loop)
- 에이전트는 초안 작성 후 `pipeline/harness.py`를 직접 실행하여 이모지 배제, 마크다운 헤더 기반 섹션 유효성, Mermaid 다이어그램을 검증하며, 미통과 시 자체 수정 루프를 가동함.

### D-5. 사용자 컨펌 게이트웨이 (User Confirmation Gate - Mandatory)
- **에이전트는 하네스를 100% 통과한 초고를 사용자에게 제시한 후 반드시 대기함.**
- **사용자의 명시적 컨펌(승인)이 있기 전에는 어떠한 경우에도 `git commit` 및 `git push`를 실행하지 않음.**
- 사용자와의 대화형 피드백을 통해 최종 수정이 완료된 후 승인 시에만 Git 커밋 및 배포를 진행함.

## 3. 결과 및 기대 효과 (Consequences)

### 긍정적 효과
- **품질 극대화:** AI 에이전트가 코드베이스 전체 맥락을 이해하고 하네스 자가 교정을 거치므로 초안의 완성도가 비약적으로 상승함.
- **통제권 확보:** 사용자 컨펌 게이트웨이를 통해 승인되지 않은 초안이 커밋되는 문제를 원천 차단함.
- **수고 절감:** 사용자는 17:00에 준비된 고품질 초고 요약을 확인하고 컨펌만 수행하면 됨.
