*4교시. 웹 서버 연결하기 — IP 주소로 첫 웹페이지 열기*

**선택 확장 — VLAN·라우터를 포함한 큰 네트워크 만들기**까지 완료 후 pkt 파일로 결과물 저장함.


*5교시. DNS 서버 연결하기 — 이름을 물어 IP 주소 받기*

**선택 확장 — DNS 응답 주소를 바꿔 다른 웹 서버와 비교하기**까지 완료 후 pkt 파일로 결과물 저장함.


*6교시. 웹 서버와 DNS 합치기 — 이름으로 웹페이지 열기*
