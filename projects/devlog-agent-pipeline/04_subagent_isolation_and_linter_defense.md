# DevLog Agent Pipeline: 서브에이전트 컨텍스트 격리와 하네스 린터 심층 방어 아키텍처

## 1. 개요
단일 세션 장기 운영 시 발생하는 컨텍스트 과부하(Context Bloat)와 토큰 비효율을 극복하기 위해 서브에이전트 격리 패턴을 도입하고, 한국어 린터의 괄호 영단어 결정론적 검출 및 외부 설정 분리를 통해 엔지니어링 거버넌스를 고도화한 구축 기록입니다.

## 2. 단일 세션 장기 운영의 한계와 서브에이전트 격리 전환
- **문제점:** 매일 정기 스케줄이 동일 세션에서 누적 실행될 때 수만 줄의 소스코드, 커리큘럼 명세, 빌드 로그가 대화 히스토리에 쌓여 추론 레이턴시와 비용이 급증하고 과거 맥락이 오염되는 결함 발생.
- **해결 (Subagent Context Isolation):**
  - 메인 에이전트는 타겟 식별(1단계)과 최종 컨펌 대기(5단계)만 담당.
  - 무거운 작업(인제스트, 5단 초안 작성, 하네스/빌드 자가 교정)은 독립된 1회용 메모리를 가진 서브에이전트(`invoke_subagent`)에게 위임하여 메인 세션의 메모리를 0KB 상태로 유지.
  - **토큰 최적화:** 서브에이전트는 검증 완료 후 본문 전문 출력을 생략하고, 생성된 파일 마크다운 링크와 핵심 의사결정 요약만 메인 세션에 반환하여 토큰 소비량 80% 이상 절감.

## 3. 하네스 린터의 4중 심층 방어 및 설정 디커플링
- **괄호 영단어 병기 하드 게이트 (`check_parentheses_english`):** 프롬프트 지시만으로 새어나가던 `경보(Alert)`, `도구(Tool)` 같은 번역투 괄호 병기를 결정론적 정규식으로 기계적 차단(`exit 1`).
- **대문자 기술 약어 정규식 자동 허용:** `r"^[A-Z0-9]{2,6}$"` 패턴을 적용하여 `JWT`, `AES`, `RSA`, `SSO`, `WAF` 등 공인 기술 약어는 목록 없이 자동 허용.
- **화이트리스트 외부 JSON 분리 (`whitelist.json`):** 파이썬 소스코드 내 하드코딩을 제거하고 독립 설정 파일로 분리.
- **기계적 복합 대구 소프트 경고 분리:** 단순 접속사를 무차별 차단하지 않고 양산형 복합 패턴(`뿐만 아니라 .+도 .+을 통해`)만 `[알림]` 경고로 분리하여 오탐/과교정 원천 차단.

## 4. 스킬 선행 로드(Pre-loading) 체크리스트 표준화
- 서브에이전트 호출 템플릿에 `exploring-codebases`, `searching-codebases`, `humanize-korean` 스킬 경로를 하드코딩하여 1턴에서 무조건 프로토콜을 로드하고 시작하도록 강제.
