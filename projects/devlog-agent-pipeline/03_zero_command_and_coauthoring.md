# DevLog Agent Pipeline: Push 이벤트 즉시 트리거와 Antigravity 대화형 Co-Authoring 설계

## 1. 개요
완전 무인 Cron 스케줄러의 태생적 한계를 극복하고, 개발자가 일체의 명령을 내리지 않아도 초안이 대기하며 Antigravity 에이전트와 실시간 대화로 수정/컨펌하는 워크플로우 구축 기록입니다.

## 2. GitHub Actions Cron의 한계와 실시간 Push 트리거 전환
- **문제점:** GitHub Actions의 무료 Cron 스케줄러는 실행 지연(수 시간 딜레이) 및 미실행(Drop) 위험이 상존하여 정시 배포의 안정성이 떨어짐.
- **해결:** `agent_core/**`, `network_zt/**`, `projects/**` 경로에 코드가 `git push`되는 순간 즉시 트리거되는 Push 이벤트 기반 자동 생성을 메인으로 전환하고, 18시 Cron은 보조 백업으로 유지.

## 3. "Zero-Command 자동 초안 대기 + Antigravity 대화형 컨펌" 아키텍처
- **사용자 경험(UX) 혁신:**
  - 사용자는 매번 "글 작성해줘"라는 명령을 내릴 필요가 없음.
  - 코드가 푸시되면 백그라운드에서 알아서 초안을 작성하여 저장해 둠.
  - 사용자가 Antigravity 세션을 열면 에이전트가 "대기 중인 초안"을 스스로 감지하여 브리핑.
  - 사용자는 대화창에서 실시간으로 "개념 설명 보강", "다이어그램 수정" 피드백을 전달하고, 완벽해졌을 때 원클릭으로 최종 발행 및 배포.

## 4. 프롬프트 및 콘텐츠 개연성 고도화
- **조건부 페어 프로그래밍 분기:** `*llm*.py` 파일이 있을 때만 Human-AI 페어 프로그래밍 대조를 수행하고, 없을 때는 단독 설계 의사결정 모드로 자동 전환하여 AI 환각(Hallucination) 방지.
- **개연성 복원:** 1번 목차(오늘의 핵심 개념 요약)와 2번 목차(전체 산출물 아키텍처 다이어그램)를 공식 복원하여 독자 관점의 학습 맥락을 완성.
