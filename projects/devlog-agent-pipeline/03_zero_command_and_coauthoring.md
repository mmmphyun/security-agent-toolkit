# DevLog Agent Pipeline: Scheduled Tasks와 Antigravity 대화형 Co-Authoring 설계

## 1. 개요
완전 무인 Cron 스케줄러의 태생적 한계를 극복하고, 개발자가 일체의 명령을 내리지 않아도 초안이 대기하며 Antigravity 에이전트와 실시간 대화로 수정 및 컨펌하는 워크플로우 구축 기록입니다.

## 2. GitHub Actions Cron의 한계와 Antigravity Scheduled Tasks 전환
- **문제점:** GitHub Actions의 무료 Cron 스케줄러는 실행 지연(수 시간 딜레이) 및 미실행(Drop) 위험이 상존하고, 실행 중 에이전트와의 실시간 대화형 피드백이 불가능함.
- **해결:** Antigravity IDE 전역의 `Scheduled Tasks` 기능(평일 17:20 정기 크론: `20 17 * * 1-5`)을 정식 워크플로우로 채택하여, 수업 종료 시점에 에이전트가 스스로 깨어나 당일 실습 코드를 분석하고 초안을 대기시키도록 설계.

## 3. "Zero-Command 자동 초안 대기 + 사용자 컨펌 게이트웨이" 거버넌스
- **사용자 경험(UX) 혁신:**
  - 사용자는 매번 "글 작성해줘"라는 명령을 내릴 필요가 없음.
  - **Scheduled Tasks 트리거:**
  - 평일 17:20이 되면 에이전트가 `harness.py --scan-pending`으로 미작성 일차를 탐색하고 커리큘럼 허브에서 세부 실습 내용을 자동 인제스트하여 5단 ADR 초안을 완성.
  - 일과 후 수동으로 작성하지 않아도 고품질의 기술 초안이 자동으로 대기함.
  - **하네스 & Astro 빌드 2중 자가 교정:** `pipeline/harness.py`와 `npm run build`를 직접 실행하여 100% 통과할 때까지 자체 수정 루프 수행.
  - **MANDATORY CONFIRMATION GATE:** 하네스를 통과한 초고 전문을 사용자에게 보고하고 멈춰서 대기. 사용자가 승인하기 전까지는 어떠한 커밋이나 푸시도 금지.
  - **원자적 배포 시퀀스 (Atomic Commits):** 사용자가 승인하면 실습 코드 커밋 ➔ 블로그 문서 커밋(`.user_confirmed` 토큰 발급) ➔ 원격 푸시(`git push origin main`)를 순차 실행하여 깨끗한 Git 히스토리 유지.

## 4. 콘텐츠 개연성 확보 및 3단 비교 스토리라인 공식화
- **3단 대조 스토리라인 (Baseline -> Problem -> Solution):**
  1) 커리큘럼 명세에서 추출한 나이브한 베이스라인 코드(`00_baseline.py`) 제시.
  2) 실제 운영 환경 및 대용량 트래픽에서 이 코드가 깨지는 이유(비정형 데이터, 메모리 누수, 예외 미처리)와 엔지니어링 문제의식 서술.
  3) 나의 1차 구현 시도('연습/프로토타입')와 LLM 기반 구조 리팩터링('llm') 대조 분석.
- **주석의 다차원 분석:** 코드 주석을 '개념 및 원리 메모'(1번 개념 요약 섹션)와 '설계 고민 및 트레이드오프'(3·4번 의사결정 섹션)로 분리 배치하여 기술적 깊이 확보.
