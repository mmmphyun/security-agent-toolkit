# 1과목: AI·보안 자동화 기초 (agent_core)

이 디렉토리는 SKT ALEPH 1과목(AI·보안 자동화 기초)의 실습 소스코드와 리팩터링 결과물을 관리하는 공간입니다.

---

## 1. 디렉토리 구조 표준

각 일차별 실습은 `day01`부터 `day08`까지 독립된 서브 디렉토리로 구성하며, 실습에 사용되는 데이터 파일은 각 날짜 디렉토리 내부의 `logs/`에 격리하여 배치합니다.

```text
agent_core/
├── README.md                           # 과목 개요 및 가이드 (본 문서)
│
├── day01/                              # 1일차 실습 (hello.py)
├── day02/                              # 2일차 실습 (CSV 처리 및 멱등성)
├── day03/                              # 3일차 실습 (이상 징후 탐지 알고리즘)
├── day04/                              # 4일차 실습 (REST API 연동)
├── day05/                              # 5일차 실습 (Flask 웹훅 & Schedule 경보)
└── day06/                              # 6일차 실습 (LLM API 연동 및 프롬프트 엔지니어링)
```

---

## 2. 파일 명명 및 주석 작성 규칙

1. **역할 기반 파일 명명:**
   - 1차 초기 구현 프로토타입 코드: `*practice.py` 또는 `0X_*.py`
   - LLM 기반 구조 리팩터링 최적화 코드: `*llm.py`
   - 나이브한 베이스라인/샘플 코드: `00_baseline.py` 또는 `sample.py`
2. **주석 기반 문제의식 기록:**
   - 나이브한 기본 구현 대비 실무적 결함, 성능 및 예외 병목, 리팩터링 의사결정 근거를 Q&A 주석 블록으로 상세히 남깁니다.
